# 安全说明

RayaTrainer 仅用于本地单人游戏。项目不承诺、也不会尝试兼容联机对局中的修改功能；当无法证明当前处于受支持的本地会话时，Agent 应拒绝执行相关操作。

## 源码与二进制

- Managed 应用外壳、产品语义合同、设置与公共测试保持开源，可独立编译与审查。
- `RayaTrainer.Agent.dll` 以官方编译二进制随 Release 分发，其实现不进入公共源码投影。这是出于运行时安全与会话准入边界的考虑，希望对此予以理解，不必在公共场合讨论其内部细节。
- 若你出于研究或集成目的需要了解更多，欢迎通过仓库列出的联系方式私下联系维护者。

## 二进制来源

正式 Release 提供一份 Agent 二进制来源清单（`agent-release.json`），记录 DLL 的 SHA-256、对应的源提交、Agent BuildId 与文件版本，以及签名状态。该清单只能证明"这个二进制由哪个受控构建产生"，不能代替运行时限制或安全审计。

## 运行时边界

- 修改与执行请求必须在 Agent 内再次通过本地会话准入，不能只依赖界面隐藏或 Managed 客户端判断。
- 本地会话证明丢失时，持续功能状态与事务型运行时补丁应被撤销。
- Agent 通信通道仅接受本机对象所有者，并拒绝远程客户端与同名实例抢占。

如发现准入绕过或未授权接口，请通过仓库的私密安全报告渠道联系维护者；请勿公开提供可直接复现的细节。
